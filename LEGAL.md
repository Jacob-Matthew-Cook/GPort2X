# GPort2X: legal separation rules (binding for every contributor and agent)

GPort2X is a GP2X user-mode compatibility harness. It runs the USER'S OWN,
legally obtained GP2X software (firmware dump and card image) read-only. It is
published separately from any reverse-engineering project.

1. **No game, decompilation or firmware code or data.** Nothing in this repo may
   be copied or derived from: the Payback binary, the decompiled corpus
   (recomp/, link/, port/, logs/, tools/ of the decomp project), Ghidra output,
   or the GP2X firmware/rootfs. No code, no data tables, no strings, no bytes.
2. **Implement from the specification and public documentation only:**
   docs/HARNESS_SPEC.md (behaviour and interfaces), Linux UAPI headers and man
   pages, the ELF and ARM Architecture Reference Manual, OSS and FAT
   specifications, the GPL GP2X kernel sources (read for facts, not copied).
3. **Interface facts are fine:** syscall numbers, ioctl numbers, register
   offsets, device paths, file names, sizes and dates a genuine card reports.
4. **Copy protection is never bypassed.** The harness emulates a genuine device
   accurately; a genuine image passes on its own. No patching, no skipping.
5. **Nothing from the user's images is committed.** Tests needing real
   firmware, game or card data read them from paths in environment variables
   and skip when absent. Only synthetic test data (generated by our scripts)
   is committed.
6. **No trademarks or artwork.** The game's name may appear only to say what
   the harness runs.
